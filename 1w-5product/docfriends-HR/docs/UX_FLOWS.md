### 1.1 Authentication Flow

```

        ▼
┌───────────────────┐
│   Login Page      │

  └────┬───────┘             [Back to Login]
       │ Yes

  ┌────────────┐

**States:**
| State | UI | Duration |
|-------|----|----------|
| Loading OAuth | Full-screen spinner + "Google 로그인 중..." | Until OAuth completes |
| Auth success | Redirect with fade transition | 200ms |
| Auth failure | Toast error + stay on login page | — |
| Domain blocked | Inline error below button | — |

### 2.1 Member List & Search Flow

```
[Navigate to /members]
        │
        ▼
┌───────────────────────────────────────────────────────┐
│  구성원 관리                          [+ 구성원 등록]  │
│  전체 45명                                            │
│                                                       │
│  🔍 이름, 이메일, 부서로 검색   [부서 ▾] [상태 ▾]     │
│                                                       │
│  ┌─────┬──────────┬──────┬──────┬───────┬──────────┐  │
│  │ ☐  │ 이름     │ 부서  │ 직급 │ 상태  │ 입사일    │  │
│  ├─────┼──────────┼──────┼──────┼───────┼──────────┤  │
│  │ ☐  │ 🧑 김영수 │ 개발팀│시니어│🟢재직 │2024.03.01│  │
│  │ ☐  │ 🧑 이지은 │ 디자인│주니어│🟡수습 │2025.12.15│  │
│  │ ☐  │ 🧑 박민호 │ 기획팀│매니저│🟢재직 │2023.06.10│  │
│  └─────┴──────────┴──────┴──────┴───────┴──────────┘  │
│                                                       │
│  총 45명  │  ◀ 1 2 3 ... ▶  │  20건 표시 ▾           │
│                                                       │
│  [Selected: 3명]  [일괄 부서 변경] [CSV 다운로드]      │
└───────────────────────────────────────────────────────┘
```

**Interactions:**

| Action | Result |
|--------|--------|
| Click row | Navigate to `/members/[id]` (detail page) |
| Click "구성원 등록" | Navigate to `/members/new` (form page) |
| Type in search | Debounce 300ms, filter table in real-time |
| Select filter | Immediate filter, combine with search |
| Check rows | Show bulk action bar at bottom |
| Click CSV download | Download filtered results as CSV |

**Search Behavior:**
- Searches across: 이름 (name), 이메일 (email), 부서명 (department)
- Debounce: 300ms after last keystroke
- No results: Show empty state "검색 결과가 없습니다"

**State Transitions:**

```
[Form Empty] ─── fill required fields ──→ [Form Valid]
     │                                         │
     │                                         ▼
     │                                    [Click 등록하기]
     │                                         │
     │                                         ▼
     │                                  ┌──────────────┐
     │                                  │ API call      │
     │                                  │ (loading)     │
     │                                  └──────┬───────┘
     │                                    ┌────┴────┐
     │                                 Success    Failure
     │                                    │         │
     │                                    ▼         ▼
     │                              [Redirect    [Toast error]
     │                               to list]    [Stay on form]
     │                              [Toast:       [Preserve
     │                               "등록 완료"]  user input]
     ▼
[Click 취소] ──→ [Confirm dialog: "작성 중인 내용이 있습니다. 나가시겠습니까?"]
                        │                │
                     [확인]            [취소]
                        │                │
                        ▼                ▼
                  [Back to list]   [Stay on form]
```

**Validation Rules:**
| Field | Rule | Error Message |
|-------|------|---------------|
| 이름 | Required, 2-50 chars | "이름을 입력해주세요" |
| 이메일 | Required, email format, unique | "이메일 형식이 올바르지 않습니다" / "이미 등록된 이메일입니다" |
| 부서 | Required | "부서를 선택해주세요" |
| 직급 | Required | "직급을 선택해주세요" |
| 입사일 | Required, not future | "입사일을 선택해주세요" |
| 프로필사진 | Optional, max 5MB, jpg/png | "5MB 이하의 이미지 파일만 가능합니다" |

│  │  수량:      1                                     │  │

│  [결재 의견을 입력하세요                             ]  │
│                                                       │

└───────────────────────────────────────────────────────┘
```

**Approval State Machine:**

```
                    ┌────────────┐
                    │  작성중     │
                    │ (Draft)    │
                    └─────┬──────┘
                          │ [결재 요청]
                          ▼
                    ┌────────────┐
             ┌──────│  결재 대기  │──────┐
             │      │ (Pending)  │      │
             │      └────────────┘      │
        [반려]                      [승인]
             │                          │
             ▼                          ▼
      ┌────────────┐           ┌────────────────┐
      │   반려됨    │           │ Next approver  │
      │ (Rejected) │           │ exists?        │
      └────────────┘           └───┬────────┬───┘
                                   │ Yes    │ No
                                   ▼        ▼
                          ┌──────────┐ ┌──────────┐
                          │ 다음결재  │ │  승인완료 │
                          │ 대기     │ │(Approved)│
                          └──────────┘ └──────────┘

Rejection at any stage → entire document rejected.
Approval at last stage → document fully approved.
```
